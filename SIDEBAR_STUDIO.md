# Sidebar Studio

Open the existing Home Studio:

`?home_editor=1`

Then open:

`🧭 사이드바`

You can change:

- Knowledge Archive show / hide
- Knowledge Archive expanded / collapsed
- OpenAI Usage show / hide
- OpenAI Usage expanded / collapsed
- Knowledge ↔ OpenAI order
- OpenAI Usage: minimal / compact

Default public layout:

1. Language
2. Knowledge Archive
3. OpenAI · token summary

The OpenAI panel no longer shows developer-facing sync/version/setup copy.

No new SQL or secrets are required. These settings are stored inside the
existing `home_page_config.config` JSON.
