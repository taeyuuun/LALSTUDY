# Data files

For the current local beta, copy the following generated files into the
**repository root** (same directory as `app.py`):

- `method_profiles.json`
- `figure_images.json`
- `license_metadata.json`
- `research_1000.db`

`figure_cache/` should NOT be committed. It is generated locally on demand.

Before public deployment, review repository size and redistribution/licensing
requirements for every included data artifact.
